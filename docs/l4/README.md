# Материалы L4

- `screenshots/`: 16 реальных рендеров Flutter из пользовательских сценариев.
- `build_report.py`: генератор PDF с оформлением предоставленного примера L3.
- Итог: `output/pdf/PAM_L4_Manolopoulos_Aristeidis.pdf` в корне репозитория.

Для обновления снимков:

```sh
flutter test --no-pub test/ui_flow_test.dart --dart-define=CAPTURE_L4=true
```

Для пересборки отчёта нужен оригинальный PDF-пример (в репозиторий не включён),
Python с reportlab и pypdf. В Windows для редких символов используется резервный
системный шрифт; основные шрифты восстанавливаются из PDF-примера.

```sh
python docs/l4/build_report.py --reference "C:/Users/user/Desktop/PAM_L3_report.pdf"
```

Титульный лист сохраняется из примера с заменой номера и темы работы.
Основной текст, синие заголовки, поля, блоки кода, подписи и расположение снимков
повторяют оформление L3. Содержание относится к L4. В отчёте указан коммит,
к которому относятся реализация и проверки; добавление самого PDF следует за ним.
